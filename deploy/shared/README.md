# VladX на shared-хостинге

Площадка VladX целиком работает в браузере (ядро — WebAssembly). Сервер нужен только
для `.vlhmn` — перевода свободного текста в программу через ИИ. Ключ Polza.ai и модель
хранятся **только на сервере**, в `config.php`; в браузер они не попадают.

## Что загрузить

Готовый архив `vladx-shared.zip` есть в каждом релизе
(<https://github.com/murfivladi/vladx_new/releases/tag/nightly>). В нём:

| Файл | Зачем |
|---|---|
| `index.html` | площадка: редактор, примеры, файлы, ядро VladX внутри |
| `vladx-llm.php` | посредник к Polza.ai: добавляет ключ и модель |
| `config.example.php` | образец настроек |
| `.htaccess` | закрывает настройки и счётчики лимитов (Apache) |

## Установка

1. Загрузите файлы в папку сайта, например `public_html/vladx/`.
2. Создайте настройки из образца. Надёжнее — уровнем выше папки сайта, в `vladx-config.php`
   (туда веб-сервер файлы не отдаёт); можно и рядом, в `config.php`:

   ```php
   <?php
   return [
       'polza_api_key' => 'ваш ключ с https://polza.ai/dashboard/api-keys',
       'model'         => 'anthropic/claude-haiku-5.5',
   ];
   ```

3. Откройте `https://ваш-сайт/vladx/` — площадка сама найдёт `vladx-llm.php` рядом.
   Проверка сервера: `https://ваш-сайт/vladx/vladx-llm.php` должен ответить
   `{"available":true,"model":"anthropic/claude-haiku-5.5",...}` (ключ в ответе не показывается).

Нужны PHP 7.2+ и расширение curl (или `allow_url_fopen`). Сайт должен открываться по `https://`:
браузер даёт хранилище файлов и фоновый поток только защищённым страницам.

## Модель и расходы

Модель меняется в `config.php` (`'model' => 'anthropic/claude-sonnet-5.5'` — точнее, но заметно дороже).
Перевод одного короткого текста на `claude-haiku-5.5` стоит порядка 0,1 ₽. Повторный запуск того же
текста берётся из кэша и запросов не тратит.

## Защита ключа

Ключ платный, поэтому посредник:

- сам выбирает модель и лимит длины ответа — клиент их не задаёт;
- принимает только диалог перевода `.vlhmn` для VladX, а не произвольные запросы;
- ограничивает число запросов: `per_ip_per_hour` (с одного адреса в час) и `per_day` (всего в сутки);
- отказывает страницам с чужих сайтов (свой сайт разрешён; другие — `allowed_origins`);
- для CLI можно включить токен `access_token` (латиница и цифры) — тогда `vladx` шлёт его из `VLADX_LLM_PROXY_TOKEN`.

Счётчики лимитов лежат в папке `vladx-data/` рядом со скриптом (путь — `data_dir`).

## CLI с тем же сервером

Ключ на компьютере не нужен — `vladx` ходит через ваш сервер:

```bash
export VLADX_LLM_PROXY=https://ваш-сайт/vladx/vladx-llm.php
```

```bash
vladx run examples/ru/14-shopping.vlhmn
```
